## PHASE 2 — DESIGN SYSTEM FIRST

Establish the design system before building pages.

Define:
- Brand-aligned color palette (warm stone, sage, cream, charcoal — restrained)
- Surface hierarchy
- Typography pairing (expressive editorial serif + clean sans; avoid Inter/Roboto/Arial/system defaults)
- Type scale
- Spacing scale
- Radius rules (restrained; not pill-everything)
- Border/shadow treatment (minimal; no multi-layer glow stacks)
- Button/input styles (primary Book, secondary Gift, tertiary Call)
- Hover/focus/active states
- Light approach by default (soft luxury, not dark mode)

Use a disciplined design system:
- Tailwind classes map to consistent tokens and repeated patterns
- Avoid arbitrary one-off styling
- Reuse through components
- Keep visual consistency across the whole site

### Design standards
- Premium but commercially effective
- Mobile-first and responsive
- WCAG-conscious: semantic structure, keyboard clarity, visible focus states
- Clear conversion hierarchy
- Strong trust signals
- Fast, clean, believable, modern
- Clean component architecture
- Production-quality front-end decisions

### Visual rules
- Modern spacing and strong alignment
- Restrained palette
- Sharp, premium, full-bleed hero (brand is a hero-level signal)
- Varied section rhythm — not repeated template blocks
- Motion enhances clarity and presence, not noise
- Redesign must be visibly stronger than the current site

### Avoid these mistakes
- Generic AI hero copy
- Repetitive 3-column feature grids with icons in circles
- Overuse of gradients/glows
- Weak spacing or weak type hierarchy
- Overrounded UI everywhere
- Generic SaaS sections that don’t fit a spa
- Unnecessary codebase complexity
- Bloated component structure for simple sections
- Purple-on-white / purple-to-indigo defaults
- Warm cream + terracotta “AI brochure” cliché
- Dark neon medspa look
